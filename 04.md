### (ii) Spliting Whitespaces

- re - Regular Expressions Operation
- It is a python library which are specialized strings used for searching, matching, and manipulating text patterns.
- Here we use this library to split the any given text based on the whitespaces or any other charater in the text

``` py
import re                # re = Regular expression operations

text = "Hello, world. This, is a test."
result = re.split(r'(\s)', text)             # (/s) : Split whitespaces

print(result)             # Output : ['Hello,', ' ', 'world.', ' ', 'This,', ' ', 'is', ' ', 'a', ' ', 'test.']
```

<br>

### (iii) Spliting whitespaces (\s) and commas, and periods ([,.]):

``` py
import re 

text = "Hello, world. This, is a test."
result = re.split(r'([,.]|\s)', text)

print(result)     # Output : ['Hello', ',', '', ' ', 'world', '.', '', ' ', 'This', ',', '', ' ', 'is', ' ', 'a', ' ', 'test', '.', '']
```

<br>

### (iv) Removing Whitespaces

- **`Remove whitespaces`** → saves memory and computation, tokenizer becomes simpler.
- **`Keep whitespaces`** → useful when text structure matters (like Python indentation/code formatting).

- **`item.strip()`** : It used to remove leading and trailing characters from a string.
- By-default it removes whitespaces

``` py
import re 

text = "Hello, world. This, is a test."
result = [item for item in result if item.strip()]      # Remove Whitespaces

print(result)       # Output : ['Hello', ',', 'world', '.', 'This', ',', 'is', 'a', 'test', '.']
```

<br>

### (v) Spliting on Special character

``` py
import re

text = "Hello, world. Is this-- a test?"
result = re.split(r'([,.:;?_!"()\']|--|\s)', text)
result = [item.strip() for item in result if item.strip()]

print(result)        # Output : ['Hello', ',', 'world', '.', 'Is', 'this', '--', 'a', 'test', '?']
```

<br>

### (vi) Basic Tokenizer for the-verdict

``` py
import re 

preprocessed = re.split(r'([,.:;?_!"()\']|--|\s)', raw_text)
```
